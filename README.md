# Memory Game

A modern, responsive memory card matching game built with React and Vite.

![Memory Game Screenshot](https://github.com/rxiddhi/memory_game/raw/main/public/brain.svg)

## Features

- 🎮 Dynamic grid size (2x2 to 10x10)
- 🎯 Move counter and timer
- 🎨 Beautiful gradient design
- 🎉 Celebration animation on win
- 📱 Fully responsive layout
- 🚀 Fast and optimized performance

## Live Demo

Try the game here: [Memory Game Demo](https://rxiddhi.github.io/memory_game)

## How to Play

1. Choose your grid size (2-10)
2. Click cards to flip them
3. Find matching pairs
4. Complete the game with minimum moves
5. Try to beat your best time!

## Technologies Used

- React 18
- Vite
- CSS3 with modern features
- Mobile-first design

## Local Development

### Prerequisites

- Node.js (v14 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/rxiddhi/memory_game.git
   ```

2. Navigate to project directory:
   ```bash
   cd memory_game
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start development server:
   ```bash
   npm run dev
   ```

5. Build for production:
   ```bash
   npm run build
   ```
